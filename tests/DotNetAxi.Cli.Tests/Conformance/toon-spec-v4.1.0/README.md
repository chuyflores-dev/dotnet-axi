# TOON v4.1 Encoder Corpus

The `encode/` fixtures and `LICENSE` are copied unchanged from
[`toon-format/spec` tag `v4.1.0`](https://github.com/toon-format/spec/tree/v4.1.0)
at commit `be5c1495987aad5a3f54636d8179139cd824c7bb`.

The production encoder uses the canonical comma delimiter and two-space
indentation. Tests execute every corpus case for that profile and inventory
the remaining option-specific cases. Per-file SHA-256 hashes prevent an
unreviewed corpus change.
