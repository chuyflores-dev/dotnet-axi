# dotnet-axi 0.2.0

This is the first public `dotnet-axi` package. It establishes the
workspace-aware, agent-facing foundation for later capability releases.

## Included

- A .NET tool package named `dotnet-axi`, installed as the `dnaxi` command.
- Deterministic structured output using schema `dotnet-axi/v1`.
- A passive home view that summarizes the current .NET workspace and available
  Git state without loading compiler analysis.
- Structured `--help` and `--version` output suitable for agent discovery.
- Workspace discovery and selection, worktree and changed-scope modeling,
  project and framework coverage, normalized locations, and snapshot identity
  as foundations for upcoming commands.
- A packaged, on-demand Agent Skill with one-shot `dnx` guidance and bounded
  recovery guidance for sandboxed Codex environments.
- Nonpublishing candidate verification for package metadata, checksums,
  symbols, global and local installation, and one-shot execution on current
  GitHub-hosted Linux, macOS, and Windows runners.

## Public CLI surface

The 0.2.0 command surface is intentionally small:

```text
dnaxi
dnaxi --help
dnaxi --version
```

The installed version's structured help is the authority for available
commands and options.

## Known limitations

- Search, structural, symbol, context, analysis, validation, modification, and
  setup subcommands are not exposed yet.
- The package targets .NET 10. Earlier SDK and runtime versions are not part of
  this release.
- Hosted-runner candidate smoke tests are release evidence, not a full platform
  or runtime support matrix.
- This release makes no measured agent-task benchmark or performance claim.
- The Agent Skill is portable guidance only; it does not install hooks, edit
  agent configuration, or change sandbox, approval, trust, or network policy.
- No persistent index, daemon, or background service is included.
